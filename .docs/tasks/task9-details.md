# Task9 - Quick Trade Mode
Place order panel have a new quick trade mode
User create quick trade buttons on UI
For example:
* Buy/Sell 25%/50%/100%
* Buy/Sell at current price +/- X
* Buy/Sell at current price +/- X%

Similar for futures trade.

Requirement:
* Have a quick trade mode toggle
* Have a setting button, popup a setting UI to config a list of button, can add/remove/update config, adjust order, once save, generate buttons in place order panel.
* provide options include trade side(buy/sell/open_long/...), position(25%/50%/...), price(market/limit), price offset(+/- X or +/- X%)
* provide style ooptions, color
